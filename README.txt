Cómo subirla a Cloudflare Pages:
1. En Cloudflare, selecciona “Upload your static files”.
2. Escribe un nombre de proyecto, por ejemplo: lumveria.
3. Arrastra esta carpeta completa o el archivo ZIP.
4. Pulsa Deploy site.
5. Cuando se publique, entra al proyecto > Custom domains.
6. Agrega lumveria.com y después www.lumveria.com.

La página no usa librerías externas, botones ni formularios.
Es responsive y funciona en móvil, tablet y computadora.
